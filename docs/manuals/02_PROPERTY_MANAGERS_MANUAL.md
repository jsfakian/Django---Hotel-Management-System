# Nephele Hotel Management System - Property Manager Manual

## Overview

Welcome to the **Nephele Property Manager Manual**. This guide is for hotel managers and property supervisors responsible for the day-to-day operations of one or more hotel properties, including staff management, guest operations, and property-specific configuration.

As a Property Manager, you have comprehensive access to your assigned property/properties but cannot access system-wide administration features.

## Getting Started

### Prerequisites
- You have been assigned a Property Manager account by the system administrator
- You have access to the Nephele system via a web browser
- You know which property/properties you manage

### System Access
- **URL**: Access Nephele via your hotel's designated system URL
- **Browser Compatibility**: Chrome, Firefox, Safari, or Edge (latest versions recommended)
- **Device**: Can be accessed from office computer, tablet, or smartphone

## Logging In

### Login Steps

1. Navigate to the Nephele login page
2. Enter your **username** (provided by administrator)
3. Enter your **password** (you may have been given temporary password)
4. Click **"Sign In"** button

**Screenshot Reference**: See `sign_in_up.jpg` in the Screenshots folder

### First Login

On your first login:
1. You may be prompted to verify your email
2. Check spam/promotions folder if verification email doesn't appear
3. Complete the verification process
4. Review and update your profile information
5. Set your preferred contact methods and notifications

### Password Management

**Change Your Password**:
1. Click your profile name in top-right corner
2. Select **"Account Settings"**
3. Click **"Change Password"**
4. Enter current password
5. Enter new password (strong password recommended)
6. Confirm new password
7. Click **"Update Password"**

**Forgot Password**:
1. On login page, click **"Forgot Password?"**
2. Enter your email address
3. Check email for reset link
4. Follow link to create new password
5. Log in with new credentials

## Guest Check-In & Check-Out

### Check-In Process

**Prerequisites**: Guest reservation exists and payment is confirmed

**Step-by-Step Check-In**:

1. Navigate to **"Bookings"** → **"Today's Check-Ins"**
2. See list of guests arriving today
3. Click on guest name
4. Verify details:
   - Check-in date (should be today)
   - Check-out date
   - Room type reserved
   - Number of guests
   - Special requests/notes

5. Confirm payment status – must show "Paid" or "Verified"

6. If payment not confirmed:
   - Contact guest to obtain payment
   - Process payment through system
   - Confirm payment verification

7. Assign room:
   - System may suggest a room
   - Or you can manually select an available room
   - Ensure room status is "Clean" and "Ready"

8. Complete check-in:
   - Print or email key/access information
   - Note any special requests in system
   - Add any walk-in items (pets, extra beds, etc.) if applicable

9. Click **"Confirm Check-In"** or **"Complete Check-In"**

### Check-Out Process

**Step-by-Step Check-Out**:

1. Navigate to **"Bookings"** → **"Today's Check-Outs"**
2. See list of guests departing today
3. Click on guest name to open their booking
4. Check guest account:
   - Final bill/invoice
   - Any outstanding charges
   - All services settled

5. If outstanding balance exists:
   - Collect payment from guest
   - Process payment in system
   - Mark as settled

6. Settle final bill:
   - Review all charges (room, meals, services, etc.)
   - Remove any test charges or errors
   - Generate final invoice
   - Send to guest

7. Process check-out:
   - Note room condition (damages, items left behind)
   - Collect key/access items
   - Mark room status as "Needs Cleaning"
   - Assign to housekeeping for turnover

8. Click **"Confirm Check-Out"** or **"Complete Check-Out"**

9. Optional - Request feedback:
   - Ask guest to complete brief survey
   - Record any comments about stay

### Managing Check-In/Check-Out Issues

**Guest Arrives Early**:
1. Check if a room is available and ready
2. If available: Process early check-in and adjust dates in system
3. If not available: Offer guest options (lounge access, luggage storage, etc.)

**Guest Discovers Room Issues**:
1. Note the specific issue in the system
2. If critical (plumbing, heating): Move guest to different room
3. If minor: Offer housekeeping visit during stay
4. Document issue for maintenance team

**Guest Wants to Extend Stay**:
1. Check room availability for additional night(s)
2. Check guest's payment method still valid
3. Add additional night(s) to booking
4. Update check-out date
5. Process payment for additional nights
6. Confirm new check-out date with guest

## Room Management

### Room Status Overview

**Understanding Room Status**:

| Status | Description |
|--------|-------------|
| **Available** | Clean and ready for guests |
| **Occupied** | Currently occupied by guest |
| **Needs Cleaning** | Guest has checked out, needs housekeeping |
| **Cleaning** | Housekeeping is cleaning the room |
| **Maintenance** | Requires repair or maintenance |
| **Out of Service** | Unavailable for guests (renovation, major repair) |

### Viewing Room Status

**Real-Time Room Status**:
1. Go to **"Rooms"** from main menu
2. See visual display of all rooms with:
   - Room number
   - Current status
   - Room type and capacity
   - Guest name (if occupied)
   - Check-out date (if occupied)

**Screenshot Reference**: See `room_list.jpg` for room management interface

### Room Type Pricing

**View Room Prices**:
1. Go to **"Rooms"** → **"Room Types"**
2. See all room types with:
   - Room type name (Single, Double, Suite, etc.)
   - Capacity (number of guests)
   - Base price
   - Number of each type available

**Adjust Room Pricing** (if authorized):
1. Click on room type
2. Modify **"Base Price"**
3. Click **"Save Changes"**
   
**Note**: Temporary price changes may require admin approval depending on your permissions

### Reporting Room Issues

**Report Room Damage or Maintenance Need**:
1. Go to **"Rooms"** → **"Maintenance Requests"**
2. Click **"Report Issue"** or **"Create Maintenance Request"**
3. Provide details:
   - **Room Number**: Which room has the problem
   - **Issue Type**: Plumbing, Electrical, Furniture, Appliance, Cleaning, Other
   - **Severity**: Low (non-urgent), Medium, High (guest affected), Critical (safety issue)
   - **Description**: Detailed description of the problem
   - **Attach Photo** (optional but helpful)

4. Click **"Submit Maintenance Request"**
5. System assigns to appropriate team
6. Track status of repair in system

### Housekeeping Coordination

**Assign Rooms to Housekeeping**:
1. After guest check-out, room status should be "Needs Cleaning"
2. Go to **"Housekeeping"** → **"Room Assignments"**
3. View rooms needing cleaning
4. View which housekeeping staff is available
5. Click room and assign to staff member

**Monitor Cleaning Progress**:
1. Go to **"Housekeeping"** → **"Status Board"**
2. View rooms being cleaned in real-time
3. Priority rooms (VIP guests, urgent turnover):
   - Flag as "Priority Cleaning"
   - Staff will focus on these first

## Bookings & Reservations

### Booking Overview

**Bookings Management** shows:
- Current and upcoming reservations
- Guest details
- Payment status
- Room assignments
- Special requests

### Viewing Bookings

**View All Bookings**:
1. Navigate to **"Bookings"** from main menu
2. Default view shows active/upcoming bookings
3. See table with:
   - Guest name
   - Check-in and check-out dates
   - Room assigned
   - Payment status
   - Special requests summary

### Filtering Bookings

Filter by:
- **Status**: Confirmed, Pending, Cancelled
- **Dates**: Specific date range
- **Guest name**: Search for specific guest
- **Room**: Filter by room or room type
- **Payment status**: Paid, Pending, Failed

### Booking Details

**View Booking Details**:
1. Click on a booking in the list
2. See complete booking information:
   - **Guest Information**: Name, email, contact details
   - **Booking Dates**: Check-in, check-out, length of stay
   - **Room Assignment**: Room number and type
   - **Pricing**: Rate per night, total number of nights, total cost
   - **Payment Information**: Payment method, amount, status
   - **Special Requests**: Any special requirements guest requested

### Modifying Bookings

**Change Room Assignment**:
1. Open booking
2. Click **"Change Room"**
3. Select different room from available options
4. Click **"Confirm Room Change"**
5. System updates booking and notifies guest (if applicable)

**Extend Stay**:
1. Open booking
2. Click **"Extend Booking"** or modify check-out date
3. Select new check-out date
4. System calculates additional cost
5. Process payment for additional nights
6. Click **"Confirm Extension"**

**Shorten Stay**:
1. Open booking
2. Click **"Modify Booking"**
3. Change check-out date to earlier date
4. System may show refund owed if payment already received
5. Process refund if applicable
6. Click **"Confirm"**

**Add Special Request**:
1. Open booking
2. Go to **"Special Requests"** section
3. Add new request (extra pillows, late checkout, etc.)
4. Note if this requires extra charge
5. Click **"Save Request"**

### Handling Cancellations

**Cancel Booking**:
1. Open booking
2. Click **"Cancel Booking"**
3. Select **"Reason for Cancellation"**
4. System shows refund amount per cancellation policy
5. Confirm cancellation
6. Click **"Process Cancellation"**

**Refund Processing**:
1. System calculates refund based on cancellation policy
2. If refund owed, it's automatically processed
3. Guest receives refund email with details

**Screenshot Reference**: See `refund_mail.jpg` for refund notification example

### No-Show Handling

**Guest Does Not Arrive**:
1. If guest doesn't check in by agreed time
2. Try contacting guest first (call/email)
3. If unable to reach after 24 hours:
   - Go to booking
   - Mark as **"No-Show"**
   - Charge applies per cancellation policy
   - Room becomes available to rent to others

## FAQ & Troubleshooting

### Q: I can't see one of my properties in the system.
**A**: Check if you're logged in with the correct account. If still missing, contact system administrator to verify property assignments.

### Q: How do I handle a guest who claims they made a reservation but I can't find it?
**A**: 
1. Search bookings by guest name and phone number
2. Check if email confirmation went to spam
3. Ask for booking confirmation number or email
4. Check if booking was made under different email address
5. If no record found, contact administrator to investigate

### Q: Can I refund a guest outside the normal cancellation policy?
**A**: This depends on your authorization level. For special refund requests, contact the system administrator who may have authority to override policies.

### Q: What do I do if a guest overstays and won't leave?
**A**: 
1. Attempt friendly conversation to resolve
2. Escalate to security/management if needed
3. Document incident in system
4. Contact administrator if legal action needed

### Q: How do I handle a maintenance emergency (broken plumbing, electrical fire, etc.)?
**A**:
1. Immediately move guest to safe location or different room
2. Call emergency services if there's danger
3. Create urgent maintenance request in system
4. Notify administrator immediately
5. Provide guest with room at no charge due to situation

### Q: Can I see staff vacation schedules?
**A**: Yes, go to **"Staff"** → **"Schedules"**. You can view who is on leave and plan coverage accordingly.

### Q: How do I add a new room type if I have new rooms?
**A**: Contact your system administrator. Room types are typically set up at the property configuration stage and may require admin access to modify.

### Q: Can guests modify their own bookings through our website?
**A**: This depends on system configuration. Some systems allow guest self-service modifications. Check your **"Settings"** → **"Guest Portal"** to see what's enabled.

### Q: What if a guest payment fails during check-in?
**A**:
1. Try alternative payment method
2. Try processing payment again
3. Contact guest's bank if issue persists
4. Document issue in booking
5. If unresolved, refuse check-in per payment policy

### Q: How do I know if a room is truly clean and ready?
**A**: 
1. Housekeeping marks room as complete
2. You can mark room status as "Available"
3. For VIP guests, you may conduct spot check
4. Photos in housekeeping system show cleaned rooms

### Q: Can I change pricing for tomorrow or next week?
**A**: Check your authorization level. Some systems allow managers to set pricing. Go to **"Rooms"** → **"Pricing"** to try. If option is restricted, request changes from administrator.

### Q: How do I handle a guest complaint about another guest?
**A**:
1. Document complaint in guest profile notes
2. Take appropriate action (noise warning, room change, etc.)
3. Ensure complaining guest is satisfied
4. Note incident for property management records

### Q: What's the difference between "Cancelled" and "No-Show"?
**A**: 
- **Cancelled**: Guest actively cancelled reservation
- **No-Show**: Guest made reservation but never arrived or checked in
