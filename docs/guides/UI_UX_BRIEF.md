# Nephele UI/UX Brief

## Product

Nephele is a multi-property hotel management platform (ops) with a guest-facing portal for stays, invoices, services, and GDPR.

## Roles

| Role | Primary jobs |
|------|----------------|
| Guest | See upcoming stay, manage bookings, pay/invoices, request services, privacy |
| Receptionist | Check-in/out, bookings, guests, payments |
| Manager | Bookings, rooms, revenue, contracts, analytics |
| Staff | Assigned tasks |
| Admin | Full configuration + all modules |

## Journeys

1. **Discover** — Landing → Sign in / Register
2. **Arrive** — Guest dashboard → booking detail / check-in status
3. **Stay** — Room services, events, notifications
4. **Settle** — Invoices, payments, refunds
5. **Privacy** — GDPR export / deletion

Ops journeys stay tool-first (front desk queue, pricing, property setup).

## Visual direction

Aegean hospitality: sea teal, sand accents, warm paper, Fraunces + Source Sans 3. Public pages lead with place; guest pages lead with the stay; ops pages stay dense and clear.
