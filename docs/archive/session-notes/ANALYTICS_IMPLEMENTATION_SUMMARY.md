## API Specification

### New Endpoints

**Executive Dashboard**
- `GET /api/v1/analytics/executive-dashboard/` - List metrics
- `GET /api/v1/analytics/executive-dashboard/current/` - Latest data
- `GET /api/v1/analytics/executive-dashboard/trend/` - Historical trends

**Operational Dashboard**
- `GET /api/v1/analytics/operational-dashboard/current/` - Real-time status

**Revenue Analytics**
- `GET /api/v1/analytics/revenue-analytics/` - List metrics
- `GET /api/v1/analytics/revenue-analytics/summary/` - Summary statistics
- `GET /api/v1/analytics/revenue-analytics/by_source/` - Revenue by booking source

**Guest Analytics**
- `GET /api/v1/analytics/guest-analytics/` - List analytics
- `GET /api/v1/analytics/guest-analytics/segments/` - Guest segmentation
- `GET /api/v1/analytics/guest-analytics/churn/` - Churn analysis

**Custom Reports**
- `GET /api/v1/analytics/custom-reports/` - List reports
- `POST /api/v1/analytics/custom-reports/` - Create report
- `POST /api/v1/analytics/custom-reports/{id}/generate/` - Generate/export
- `GET /api/v1/analytics/custom-reports/{id}/download/` - Download file

**Dashboard Summary**
- `GET /api/v1/analytics/dashboard/summary/` - Combined dashboard data

## Deployment & Setup

### To Deploy:

1. **Create migrations:**
   ```bash
   python manage.py makemigrations analytics
   ```

2. **Apply migrations:**
   ```bash
   python manage.py migrate analytics
   ```

3. **Verify installation:**
   ```bash
   python manage.py shell
   >>> from analytics.models import DashboardExecutiveMetrics
   >>> DashboardExecutiveMetrics.objects.all().count()
   0
   ```

4. **Configure Celery tasks:**
   - Add to celerybeat schedule:
   ```python
   'analytics-nightly-etl': {
       'task': 'analytics.tasks.nightly_etl_pipeline',
       'schedule': crontab(hour=2, minute=0),  # 2 AM UTC
   }
   ```
